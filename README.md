# Employee KPI Dashboard – Microsoft Excel

## Project Overview
This project is an Employee KPI Dashboard developed using Microsoft Excel to monitor employee attendance and performance.

## Key Features
- Total Employees
- Present Employee Count
- Absent Employee Count
- Employees on Leave
- Average Performance
- Attendance Percentage
- Attendance Breakdown Chart
- Department-wise Employee Chart
- Automatic KPI Calculations

## Tools Used
- Microsoft Excel
- Excel Formulas
- Charts and Data Visualization
- Dashboard Design and Formatting

## Dashboard Design
The dashboard uses a professional Dark Blue and White theme with KPI cards, charts, and organized data presentation.

## Project Files
- Book1_Professional_KPI_Dashboard.xlsx

## Purpose
The purpose of this project is to provide a simple and effective way to monitor employee attendance and performance through an interactive Excel dashboard.
